# 🚗 UTEQ Smart Parking - Sistema Administrativo

Este es el panel de administración (CRUD) para el sistema de Parqueadero Inteligente de la Universidad Técnica Estatal de Quevedo (UTEQ).

## 🛠️ Tecnologías utilizadas
* **Frontend:** React + Vite
* **UI Framework:** CoreUI React Admin Template
* **Base de Datos / Backend:** Supabase (PostgreSQL)

## 📋 Características principales
* Visualización de vehículos, propietarios, puestos e historial de parqueo.
* Operaciones CRUD completas (Crear, Leer, Actualizar, Eliminar).
* Conexión en tiempo real con Supabase.
